# Ribbit Frame — identidade visual

A marca usa a logo transparente fornecida pelo usuário. O arquivo completo, já recortado, está em `src/assets/ribbit-frame-logo.png`; o ícone isolado está em `src/assets/ribbit-frame-icon.png`.

## Cores

| Papel | Cor |
| --- | --- |
| Verde da marca | `#0E3D3A` |
| Creme da superfície | `#F5EFE6` |
| Roxo de ação | `#9B59D1` |
| Laranja de detalhe | `#FFB366` |
| Grafite do editor | `#222222` |

A barra superior e a navegação usam creme para preservar a leitura da logo verde. O explorador usa grafite, a lista de pastas usa verde e as ações principais usam roxo. O laranja fica nos detalhes de estado. Texto e controles usam Inter/Segoe UI; a tipografia arredondada do nome vem do próprio arquivo de logo, sem depender de uma fonte não fornecida.

## Dados existentes

O nome de exibição e o pacote são Ribbit Frame. A pasta de dados Electron permanece em `foreditor` para manter a biblioteca já cadastrada. O protocolo interno e as chaves de IndexedDB também permanecem para evitar perda dos dados existentes.
